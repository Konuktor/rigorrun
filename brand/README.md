# brand/

[BRAND_BOOK.md](BRAND_BOOK.md) is the document. The assets it describes are **not** kept here,
because a copy of a token file is a second source of truth and the whole argument of the book is
that there should be one.

| What | Where |
| --- | --- |
| Tokens, both themes | [`packages/design/src/tokens.css`](../packages/design/src/tokens.css) |
| Type system and metric-matched fallbacks | [`packages/design/src/fonts.css`](../packages/design/src/fonts.css) |
| Typefaces (Instrument Sans, Geist Mono — OFL) | [`packages/design/fonts/`](../packages/design/fonts) |
| Logo sources | [`packages/design/logo/`](../packages/design/logo) |
| Every raster asset | generated by [`scripts/build-brand.mjs`](../scripts/build-brand.mjs) — `pnpm brand` |
| The contrast gate | [`scripts/check-contrast.mjs`](../scripts/check-contrast.mjs) — `pnpm contrast` |

The reason this is a directory of pointers rather than a directory of files: the favicon used to be
an inline data URI in `index.html` carrying `#e7eaee`, while the token said `#e9ecf1`, while a third
copy of the mark lived as a CSS border in a React component. Three copies, already disagreeing. Now
there is one mark, one token file, and a script that renders everything else from them.
