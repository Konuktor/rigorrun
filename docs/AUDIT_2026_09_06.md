# Independent Product Audit — Claim Matrix — 2026-09-06

An adversarial, end-to-end audit of the **public** RigorRun product. The question
being answered: *does the public product work for a stranger, or does it only
pass tests the authors wrote themselves?*

**Public version under test:** `rigorrun@0.1.0`
- Registry: `registry.npmjs.org`, published 2026-09-06T07:20:18Z, `latest`.
- Tarball sha1 `ccdc8a49a9b28154f97e0a6941dc0f25f0c1e8dc`, sha512 `MhR5cycS…IAV6w==`
  — **independently re-downloaded and both hashes matched the registry**.
- npx clean-room provenance: fresh `HOME`, fresh npm cache, cwd outside the
  repo, no link — the created cache holds only
  `https://registry.npmjs.org/rigorrun/-/rigorrun-0.1.0.tgz` with the published
  integrity. The clean-room path does **not** depend on repository files.

Method: everything below was executed against the artifact installed from the
public registry (or, for the offline engine, the same `@rigorrun/*` packages the
bundle inlines), in an isolated `HOME`, driving the daemon's own HTTP API exactly
as the shipped UI does, plus genuine third-party MCP servers from npm and
purpose-written adversarial servers **outside** the product core.

Legend for RESULT: **PASS** (verified working as advertised) · **PASS***
(works, narrower than the headline) · **PARTIAL** · **FAIL** · **UNVERIFIED**
(could not be tested here) · **N/A**.

Legend for SEVERITY IF BROKEN: **P0** product is unusable / lies about
safety or verification · **P1** a headline capability is broken · **P2**
narrower than advertised · **P3** cosmetic.
