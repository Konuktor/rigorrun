4. [PROGRESS.md](PROGRESS.md) — where the work stands now.
5. [DECISIONS.md](DECISIONS.md) — why things are the way they are.
6. [AGENT_WORKFLOW.md](AGENT_WORKFLOW.md) — how Claude, Codex and Cursor split the work.
